# AI at Work

AI is integrated throughout the tutorials as a learning and professional assistant.

Dedicated **AI at Work** learning paths will show how AI is used responsibly in real professions, including:

- Developers
- Data Analysts
- ML Engineers
- Project Managers
- PMO and Project Controls professionals
- Architects
- Engineers
- Designers
- QA and Test Engineers
- Data Engineers
- Cybersecurity professionals

The guiding principle is:

> **Ask → Understand → Verify → Apply**
