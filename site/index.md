# Learn with Nelson

**Learn technology from zero — understand it, practice it, build with it.**

This learning library is designed for people who want a clear starting point and a structured path forward.

You do not need a computer science degree.  
You do not need previous programming experience.  
You do not need to understand the jargon before you begin.
