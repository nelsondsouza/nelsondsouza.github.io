# Developer Roadmaps

**Build things. Learn the skills behind modern software development.**

If you are starting from zero and want to become a **Developer**, this page helps you discover the roadmaps that can build your foundation and gradually expand your skills.

You do **not** need to learn everything here.

Start with the fundamentals, then follow the areas that match the kind of software you want to build.

---

## What Does a Developer Do?

A developer turns ideas and requirements into working software.

Depending on the role, that might mean:

- Building websites and web applications
- Creating APIs and backend services
- Working with databases
- Writing automation and scripts
- Integrating external services
- Building AI-powered applications
- Testing and improving software
- Using cloud and DevOps tools
- Understanding how larger systems are designed

The exact tools may change over time.

The underlying skills remain important.

---

## Your Developer Learning Path

A simple way to think about the journey is:

**Foundations → Programming → Development → Data → APIs → Testing → Architecture → Cloud → Real Projects**

You don't have to follow every branch.

Choose based on what you want to build.

## Don't Learn Everything at Once

A common beginner mistake is trying to learn:

**Python + Java + React + Docker + Kubernetes + AWS + AI + SQL + everything else**

at the same time.

Don't.

Instead:

### Step 1 — Pick one programming language

Start with **Python** or another language that matches your goal.

### Step 2 — Learn how software is built

Move into frontend, backend or full-stack development.

### Step 3 — Build small projects

Turn what you learn into working software.

### Step 4 — Add supporting skills

Learn SQL, APIs, Git, testing and deployment.

### Step 5 — Go deeper

Choose architecture, cloud, AI, security or another specialization.

## What Should You Learn First?

If you are a **complete beginner**:

**Python → Git & GitHub → SQL → Backend or Frontend → APIs → Projects**

If you want to become a **Web Developer**:

**HTML/CSS/JavaScript → Frontend → Backend → APIs → Database → Fullstack**

If you want to become a **Backend Developer**:

**Programming → SQL → Backend → APIs → Databases → Testing → Cloud**

If you want to build **AI Applications**:

**Programming → APIs → AI Tools → AI Application Development → Deployment**

If you want to become a **Software Engineer**:

**Programming → Data & APIs → Software Engineering → Testing → Architecture → Cloud**

---

## Your Goal Is Not to Finish the Roadmap

A roadmap is a **map**, not a checklist.

You don't become a developer because you completed 30 technologies.

You become a developer by being able to:

**Understand → Build → Debug → Test → Deploy → Improve**

The real proof is what you can build.
