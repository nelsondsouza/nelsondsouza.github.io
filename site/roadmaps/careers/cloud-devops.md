# Cloud & DevOps Roadmaps

**Build, deploy, automate and operate modern software systems.**

If you want to work in **Cloud & DevOps**, this page helps you understand the skills and technologies used to deliver software reliably and operate the infrastructure behind it.

You do not need to learn every cloud provider or DevOps tool.

Start with Linux, networking, Git and automation, then progress toward cloud platforms, containers, infrastructure as code, CI/CD, observability and reliable production systems.

---

## What Does Cloud & DevOps Work Involve?

Cloud & DevOps professionals help organizations build and operate reliable technology platforms.

Typical work includes:

- Managing infrastructure
- Automating deployments
- Building CI/CD pipelines
- Managing cloud resources
- Running containers
- Managing Kubernetes environments
- Automating infrastructure
- Monitoring systems
- Managing logs and metrics
- Improving reliability
- Supporting development teams
- Responding to production problems

A simple way to think about the discipline is:

**Code → Build → Test → Deploy → Operate → Observe → Improve**

---

## Your Cloud & DevOps Learning Path

A practical journey looks like:

**Foundations → Linux → Networking → Git → Scripting → Cloud → Containers → CI/CD → Infrastructure as Code → Orchestration → Observability → Security → Reliability**

You do not need to master everything immediately.

Build one layer at a time.

---

## Recommended Roadmaps

### Start with the Foundations

Build the skills that support modern infrastructure work.

- Linux
- Bash
- Git & GitHub
- Networking
- Python
- HTTP
- DNS

Linux and networking are particularly important foundations.

---

## Learn Linux

Linux is widely used across cloud and server environments.

Learn:

- Files and directories
- Permissions
- Processes
- Users and groups
- Services
- Packages
- Environment variables
- Networking commands
- Logs
- Shell scripting

You should become comfortable working from the command line.

---

## Learn Networking

Cloud systems depend heavily on networking.

Understand:

- IP addresses
- Subnets
- Routing
- Ports
- TCP/IP
- DNS
- HTTP/HTTPS
- Firewalls
- Load balancers
- Proxies
- Private and public networks

You don't need to become a network engineer.

You need to understand how systems communicate.

---

## Git & Collaboration

Infrastructure and application delivery both depend on version control.

Learn:

- Git
- Branches
- Commits
- Pull requests
- GitHub
- Code reviews
- Git workflows

Then apply version control to infrastructure and automation.

---

## Automation & Scripting

DevOps is heavily focused on reducing repetitive manual work.

Learn:

- Bash
- Python
- Shell commands
- Environment variables
- Automation scripts
- Configuration management

Then explore tools such as:

- Ansible
- Terraform

The goal is:

**Automate repeatable work.**

---

## Choose a Cloud Platform

Start with **one** major cloud provider.

Explore:

- AWS
- Microsoft Azure
- Google Cloud

Learn the common concepts first:

- Compute
- Storage
- Networking
- Databases
- IAM
- Monitoring
- Load balancing
- Scaling

Once you understand one cloud well, learning another becomes easier.

---

## Containers

Containers package applications with the dependencies they need to run.

Learn:

- Container images
- Containers
- Dockerfiles
- Registries
- Volumes
- Networks
- Environment variables
- Container lifecycle

Then explore:

**Docker → Containerized Applications → Production Deployment**

---

## CI/CD

Continuous Integration and Continuous Delivery/Deployment automate the path from code change to production.

Learn:

- Build pipelines
- Automated tests
- Artifacts
- Deployment stages
- Environment management
- Release automation
- Rollbacks

Explore tools such as:

- GitHub Actions
- Jenkins

A simple pipeline looks like:

**Code → Build → Test → Package → Deploy**

---

## Infrastructure as Code

Infrastructure should be reproducible rather than manually configured whenever practical.

Learn:

- Infrastructure as Code
- Configuration
- State
- Variables
- Modules
- Environments
- Planning and deployment

Explore:

- Terraform

Then apply infrastructure-as-code practices to your cloud environments.

---

## Kubernetes & Orchestration

As containerized systems become larger, orchestration becomes useful.

Learn:

- Pods
- Deployments
- Services
- ConfigMaps
- Secrets
- Ingress
- Scaling
- Scheduling
- Health checks

Then understand how Kubernetes manages containerized workloads.

Don't start with Kubernetes before understanding containers.

---

## Observability

Production systems need visibility.

Learn the three major signals:

**Metrics + Logs + Traces**

Explore:

- Prometheus
- Grafana
- Logging
- Alerting
- Dashboards
- Distributed tracing
- Service health

The goal is to answer:

**"What is happening in the system right now?"**

---

## Reliability

DevOps is not only about deploying quickly.

It is also about keeping systems dependable.

Learn:

- Availability
- Reliability
- Resilience
- Scalability
- Backups
- Disaster recovery
- Health checks
- Incident response
- Capacity planning

A successful deployment is not enough if the system cannot operate reliably.

---

## Security

Security must be part of cloud and delivery practices.

Learn:

- IAM
- Authentication
- Authorization
- Secrets management
- Network security
- Encryption
- Secure configuration
- Dependency security
- Container security

Then explore:

**DevSecOps → Cloud Security → Infrastructure Security**

---

## Don't Learn Everything at Once

A common beginner mistake is trying to learn:

**AWS + Azure + GCP + Docker + Kubernetes + Terraform + Jenkins + Ansible + Prometheus + everything else**

simultaneously.

Don't.

Start with:

**Linux → Networking → Git → Bash → Cloud → Docker**

Then move toward:

**CI/CD → Terraform → Kubernetes → Observability → Security**

---

## What Should You Learn First?

### Complete Beginner

Start with:

**Linux → Networking → Git → Bash → Cloud Basics**

### Want to Become a DevOps Engineer?

Build toward:

**Linux → Git → Cloud → Docker → CI/CD → Terraform → Kubernetes**

### Want to Become a Cloud Engineer?

Build toward:

**Networking → Cloud → IAM → Infrastructure as Code → Containers → Monitoring**

### Want to Focus on Platform Engineering?

Build toward:

**Cloud → Kubernetes → Terraform → CI/CD → Observability → Developer Platforms**

### Want to Move Toward DevSecOps?

Build toward:

**Cloud → IAM → CI/CD → Security → Containers → Kubernetes → Security Automation**

---

## Cloud & DevOps vs Software Engineering

These disciplines overlap.

### Software Engineering

Often focuses more on:

**Building software → Testing → Architecture → Maintenance**

### Cloud & DevOps

Often focuses more on:

**Delivery → Infrastructure → Automation → Operations → Reliability**

Modern teams benefit when both disciplines understand each other.

---

## Build Projects

Don't stop at tutorials.

Build projects such as:

### Beginner

- Linux automation scripts
- Git workflow
- Simple deployment pipeline

### Intermediate

- Dockerized application
- CI/CD pipeline
- Terraform infrastructure
- Cloud deployment

### Advanced

- Kubernetes application
- Monitoring stack
- Highly available service
- Automated infrastructure
- End-to-end deployment platform

**Code → Infrastructure → Automation → Deployment → Monitoring**

## Your Goal Is Not to Memorize Cloud Services

Cloud providers constantly introduce new services.

Tools also change.

Your durable skills are:

**Linux → Networking → Automation → Infrastructure → Delivery → Observability → Reliability**

Understand the concepts behind the tools.

Then you can adapt.
