## How Career Roadmaps Work

A career roadmap is **not a list of everything you could possibly learn**.

It is a guided map of the skills and subjects that are useful for your chosen direction.

A single roadmap can appear under multiple careers.

For example:

**Python** can support:

- Developer
- Data Analyst
- Data Engineer
- ML Engineer
- AI Engineer
- Software Engineer

You therefore don't need duplicate roadmap pages.
