# Learn with Nelson — Topic Roadmaps

**Choose a skill. Learn the technology. Build your capability.**

You don't always start with a career.

Sometimes you simply want to learn:

- [Python](topics/python.md)
- [SQL](topics/sql.md)
- [Excel](topics/excel.md)
- [Power BI](topics/power-bi.md)
- [Docker](topics/docker.md)
- AWS
- React
- [Java](topics/java.md)
- [Kubernetes](topics/kubernetes.md)
- System Design
- AI
- Cybersecurity

That's where **Topic Roadmaps** come in.

Career Roadmaps answer:

**"What should I learn for my career?"**

Topic Roadmaps answer:

**"What should I learn about this skill or technology?"**

---

## How Topic Roadmaps Work

A topic roadmap focuses on one technology, skill, platform, concept or discipline.

For example:

**[Python](topics/python.md)**

can support:

- Developer
- Data Analyst
- Data Engineer
- ML Engineer
- AI Engineer
- Software Engineer

You therefore don't need a separate [Python](topics/python.md) roadmap for every career.

**One Topic → Multiple Careers**

# Don't Learn Everything

Technology contains thousands of tools.

You do not need all of them.

A better approach is:

**Choose a goal → Identify required skills → Learn the fundamentals → Practice → Build projects → Add advanced topics**

Avoid collecting technologies without understanding them.

---

# A Simple Learning Pattern

For any topic, follow:

**Understand → Follow Along → Practice → Build → Review → Apply**

Don't stop at watching tutorials.

The real learning happens when you use the knowledge.
